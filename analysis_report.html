🚨 Problèmes CRITIQUES (Doivent être fixés)

CRITICAL
Race Condition: Navigation Cart → Orders
📄 lib/screens/client/cart_screen.dart:143-153
Changement de tab + navigation occur sans délai, causant une collision entre deux navigateurs. Résultat: L'app se fige et les boutons deviennent non-réactifs.
Impact: Utilisateurs ne peuvent pas accéder au détail de leur commande
// ❌ AVANT (BUG) shell?.goTo(ClientShellState.ordersTab); Navigator.push(context, MaterialPageRoute(...)); // Race!
Ajouter délai 300ms avant le push
✅ FIXÉ
CRITICAL
Auth Initialization Incomplete
📄 lib/providers/auth_provider.dart:19-33
La flag `initializing` reste `true` si la connexion réseau échoue pendant init. Seul `ApiException` est catchée, pas `SocketException` ou timeouts.
Impact: App bloquée en loading eternel si pas internet
// ❌ AVANT try { user = await Api.instance.me(); } on ApiException catch (e) { // Mais TimeoutException n'est pas catchée! } // initializing resteTRUE si timeout
Catch toutes exceptions, set initializing false dans finally
CRITICAL
No Retry Logic on API Failures
📄 lib/services/api.dart:37-61
Les erreurs réseau transitoires (timeout, 500) bloquent l'app. Pas de retry automatique avec backoff exponentiel.
Impact: Utilisateurs perdent leurs commandes même pour erreur transitoire
Implémenter retry avec 3 tentatives + 200ms backoff
CRITICAL
Form Validation Doesn't Block Submit
📄 lib/screens/client/checkout_screen.dart:72-86
Validation du formulaire ne suffit pas. Utilisateur peut commander sans localisation GPS. Le champ GPS est requis pour livraison mais pas validé proprement.
Impact: Commandes sans localisation = livraison impossible
Ajouter validation custom pour GPS requis en mode livraison
✅ PARTIELLEMENT FIXÉ
CRITICAL
No Error Handling on Payment Webhook
📄 lib/models.dart (Order model)
Le champ `paymentReference` peut être null mais utilisé directement dans les écrans. Affichage du numéro de transaction peut crasher l'app.
Impact: Crash potentiel lors de l'affichage d'une commande payée
Ajouter null checks avant d'afficher payment_reference
